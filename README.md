# ShopEase 
A Ecommerce Frontend Dummy App built using react with fakestore API

## Features included
- Login,register 
- Responsive design
- View orders,manage orders
- Sorting products
- Cart implementation
- Dark/light mode support
- Dummy checkout

## Getting Started

First, run the development server:

```bash
npm install
# or
npm run dev
```
## Libraries / Technologies used
- Context Api
- Axios
- Tailwind CSS
